## Description 📄

This project is a personal portfolio website built with React, Vite, and Tailwind CSS, showcasing the skills, projects, and experience of Moe Kyaw Aung, a Senior Mobile Architect and Startup Founder. It features a dynamic and animated user interface with a particle background, custom cursor, and smooth scrolling animations.

## Features 🌟

- ✨ **Interactive Hero Section:** Engaging introduction with a typing animation and dynamic particle background.
- 🚀 **Smooth Scrolling & Animations:** `react-intersection-observer` used for animated sections on scroll.
- 🖱️ **Custom Cursor:** Enhances user experience with a custom interactive cursor.
- 🎨 **Dark Mode Toggle:** Supports both light and dark themes for user preference.
- 📱 **Responsive Design:** Optimized for various screen sizes across devices.
- ⚙️ **Modular Codebase:** Well-structured React components for maintainability.
- 💡 **Dynamic Navigation:** Sticky header that adapts to scroll position and highlights the active section.
- 🖼️ **Image Galleries & Carousels:** Showcases projects and personal moments visually.
- 🔗 **Social Media Integration:** Links to various social and professional profiles.

## Tech Stack 🛠️

- **Frontend:** React, TypeScript, HTML, CSS
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Libraries:** `react-icons`, `react-tsparticles`, `react-type-animation`, `react-intersection-observer`, `clsx`, `tailwind-merge`

## Installation 🚀

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Dev-moe-kyawaung/Moekyawaung-portfolio-website-01.git
   cd Moekyawaung-portfolio-website-01
   ```

2. **Install dependencies:**


## Usage 💡

This project serves as a personal portfolio website. It's a showcase of Moe Kyaw Aung's expertise, projects, and professional journey. The website is designed to:

- **Display Professional Profile:** Highlights skills, experience, and achievements.
- **Showcase Projects:** Features a collection of mobile apps and web applications with links to repositories or live demos.
- **Provide Contact Information:** Enables potential employers or collaborators to get in touch.
- **Demonstrate Technical Proficiency:** Utilizes modern web development technologies to create a polished and interactive experience.

To use this project:

1. **Clone the repository and install dependencies as described in the `Installation` section.**
2. **Run the development server (`npm run dev`).**
3. **Open your browser to `http://localhost:5173` (or the port specified by Vite) to view the portfolio.**

## How to use 🛠️

The website is a single-page application (SPA) designed for viewing. Users can navigate through different sections using the sticky header or by scrolling down the page. Interactive elements, such as the custom cursor and animated sections, enhance the browsing experience. The project serves as a template that can be forked and adapted for personal portfolios, with clear sections for skills, projects, contact, and personal information.
